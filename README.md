# make108 CH32V003 4-Key Gadget

数十円マイコン「CH32V003」とCR1220コイン電池1枚で駆動する、超省電力・高レスポンスなメカニカルキースイッチ型フィジェットガジェットです。  
心地よい打鍵感に同期したカラーチェンジ、11ステップ調光によるフェード、リングバッファ式「10裏コマンド」、および待機電流 約0.1mAを達成した極小Stopモードを搭載しています。

---

## 🌟 主な特徴

- **極限の省部品＆コイン電池直駆動**:
  - RISC-Vコアの極小マイコン「CH32V003F4P6」を採用。
  - CR1220 / CR1225 コイン電池（3.0V）で直駆動。外付け昇圧/降圧回路・外付けプルアップ抵抗・電流制限抵抗レスのシンプル設計。
- **100Hz固定枠スロット制御 & 青ブースト疑似PWM調光**:
  - 1キーあたり 2,500µs（4キー計10,000µs＝10ms周期／100Hz）の固定タイムスロット管理。
  - スロット枠内を「赤200µs・緑300µs・青2,000µs」の固定幅に配分し、電池駆動で暗くなりがちな青色LEDを強力にブースト。同時押し時も輝度が低下しません。
- **レスポンス重視の手遊び（フィジェット）制御**:
  - **短押し（タップ）**: 押下瞬間に即座に次の色へ切り替わる万華鏡モード（KEY4初動遅延を完全解消）。
  - **長押し**: 11ステップ指数調光カーブによる滑らかな呼吸ブリージング。
- **リングバッファ式「10大裏コマンド」**:
  - 打鍵履歴（直近8打鍵）を常時走査し、オートイルミネーションやナイトライダーなどの特殊演出が起動。
  - 成立後0.5秒の「不感帯ガード」により、勢い余ったオーバーラン打鍵を自動破棄。
- **Stopモード限界チューニング（待機電流 約0.1mA）**:
  - 5秒間の無操作で自動的に低消費電力Stopモードへ移行。
  - SysTickタイマーおよびADCを完全遮断し、キースイッチ押下のEXTI外部割り込みにより約15〜30µs（体感ラグゼロ）で超速復帰。
- **3Dプリントトレイ＆電池化粧カバー**:
  - FreeCAD（Pythonスクリプト）で自動生成可能な専用トレイおよびカバーの3D設計データを同梱。

## 🔌 ハードウェア仕様 & ピンアサイン

### 主要スペック
- **MCU**: WCH CH32V003F4P6 (TSSOP-20 / RISC-V @ 24MHz )
- **電源**: コイン電池 CR1220 
- **キースイッチ**: Cherry MX互換メカニカルスイッチ × 4
- **LED**: 1608 単色チップLED × 12（各キー 赤・緑・青）
- **基板外形**: 100.0 mm × 24.0 mm（M2ネジ穴ピッチ: 94.0 mm × 18.0 mm）

### ピンアサイン一覧
- **キースイッチ入力 (内蔵プルアップ / Active LOW)**:
  - KEY0 (SW1): **PA1**
  - KEY1 (SW2): **PD6**
  - KEY2 (SW3): **PD5**
  - KEY3 (SW4): **PC0** 
- **LED マトリクス (ROW: アノード駆動 / COL: カソードシンク)**:
  - 行 (ROW / アノード): **PC4** (KEY0), **PC5** (KEY1), **PC7** (KEY2), **PC6** (KEY3)
  - 列 (COL / カソード): **PC1** (RED), **PC2** (GREEN), **PC3** (BLUE)
- **書き込み / デバッグ (SWD)**:
  - SWDIO: **PD1**
  - NRST: **PD7** (リセット端子) 今のところ未使用

## 🎮 10裏コマンド一覧

打鍵履歴の末尾が以下のパターンと一致すると特殊演出が発動します。  
（※演出開始から0.5秒経過後、いずれかのキーを押すと即座に通常の手動モードへ復帰します）

| No. | コマンド名称 | 入力パターン（キー番号: 0〜3） | 動作内容 |
| :---: | :--- | :--- | :--- |
| **1** | **オートイルミネーション** | `0, 2, 1, 3, 0, 2, 1, 3` | 全キーが連携して7色フェード演出を自動ループ |
| **2** | **順方向ナイトライダー** | `0, 1, 2, 3` | 左から右へ光が往復スキャン（シアン） |
| **3** | **逆方向ナイトライダー** | `3, 2, 1, 0` | 右から左へ光が往復スキャン（マゼンタ） |
| **4** | **赤オンリー点滅** | `0, 0, 0, 0` | KEY0×4 / アラート風ブリンク |
| **5** | **緑オンリー点滅** | `1, 1, 1, 1` | KEY1×4 / サイバー風ブリンク |
| **6** | **青オンリー点滅** | `2, 2, 2, 2` | KEY2×4 / クール風ブリンク |
| **7** | **高速白ストロボ** | `3, 3, 3, 3` | KEY3×4 / 強烈な白色フラッシュ |
| **8** | **ピンポン** | `0, 3, 0, 3` | 両端キーが交互にバウンド点灯 |
| **9** | **中央集中ウェーブ** | `0, 3, 1, 2` | 外側から内側へ収束する光の波 |
| **10** | **強制即時スリープ** | `3, 2, 1, 3` | タイムアウト（5秒）を待たずに即時Stopモードへ移行 |

## 🛠️ ファームウェアビルド & 書き込み手順

### 1. 開発環境の準備
1. **Arduino IDE** を起動し、環境設定の「追加のボードマネージャURL」に WCH 公式パッケージ URL を登録します:
   ```text
   https://github.com/openwch/board_manager_files/raw/main/package_ch32v_index.json
   ```
2. ボードマネージャから **`CH32V`** を検索してインストールします。
3. ボード設定:
   - **Board**: `CH32V00x Series`
   - **MCU Type**: `CH32V003F4`
   - **Upload Method**: `WCH-Link` (または WCH-LinkE)

### 2. ハードウェア接続
基板右下のSWD端子に WCH-LinkE を接続します。
- `3V3` $\leftrightarrow$ 3V3
- `GND` $\leftrightarrow$ GND
- `SWD` $\leftrightarrow$ SWDIO

### 3. 推奨書き込みステップ
1. **`firmware/00_LED_Checker/`**: 基板組立直後に書き込み、LED12素子と配線パターンの導通を自動確認。
2. **`firmware/01_Key_LED_Test/`**: スイッチ実装後に書き込み、キー入力と各色LEDの連動を手動確認。
3. **`firmware/02_Fade_Breathe_Demo/`**: 疑似PWM呼吸調光の仕組み確認用。
4. **`firmware/13_Final_Firmware/`**: 本番用完全版ファームウェアを書き込み。
